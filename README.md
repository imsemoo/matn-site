# MATN landing page

Landing page for MATN, a CMS for hand-built newsroom sites: the client edits the real page, text and images, while the design stays locked. Arabic, right to left, with an English version.

**Live:** https://imsemoo.github.io/matn-site/

One static HTML page with an `assets/` folder.
